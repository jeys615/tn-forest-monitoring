## 1. Executive Summary

Module M8.6 transforms the real Google Earth Engine satellite acquisition, server-side zonal statistical reduction (`reduceRegion`), M5 dual-track index calculations, and M6 change detection into an automated, incremental monitoring pipeline for both **Permanent Monitored Zones** and **Temporary Marked Monitoring Areas**.

### Key Achievements:
- **Zero Business Logic Regressions:** All existing M1–M8.5 capabilities, mathematical indices, baseline isolation rules, and multi-threshold alerts are 100% preserved.
- **Unified Processing Flow:** Real Sentinel-2 (`COPERNICUS/S2_SR_HARMONIZED`) and Sentinel-1 (`COPERNICUS/S1_GRD`) observations are discovered incrementally since each area's `lastProcessedAcquisitionDate`.
- **Complete Incremental Lifecycle Tracking:** State progression tracked via `DISCOVERED` $\rightarrow$ `QUEUED` $\rightarrow$ `ACQUIRING` $\rightarrow$ `REDUCING` $\rightarrow$ `PROCESSING` $\rightarrow$ `CHANGE_ANALYSIS` $\rightarrow$ `ALERT_EVALUATION` $\rightarrow$ `COMPLETED`.
- **Deduplication & Idempotency:** Duplicate observations or re-runs are detected via compound unique indexes and return existing records without database record proliferation.
- **Strict Sensor & Baseline Isolation:**
  - Optical compares only to Optical baselines; SAR compares only to SAR baselines.
  - Temporary area incremental analysis never modifies, creates, or mutates permanent zone active baselines.
- **Guaranteed Ephemeral Disk Cleanup:** Ephemeral workspaces and raster tiles are deleted in all execution branches via `try ... finally` in `TempImageManager`.

## 3. Architecture & Data Flow

```
   Active Area (Permanent Zone or Temporary Monitoring Area)
                              │
                              ▼
               [AutomatedMonitoringService]
                              │
      ┌───────────────────────┴───────────────────────┐
      ▼                                               ▼
[Permanent Zone (Active)]                 [Temporary Area (Requested/Active)]
  - Requires Active M5 Baseline             - Historical Reference Comparison
  - Inactive/Suspended Excluded             - Expired/Archived Excluded
      │                                               │
      └───────────────────────┬───────────────────────┘
                              │
                              ▼
            [Incremental Observation Discovery]
  (Queries GEE Sentinel-2 / Sentinel-1 from lastProcessedAcquisitionDate)
                              │
                              ▼
                 [Idempotency / Dedup Filter]
  (Skips already processed observations using compound unique index)
                              │
                              ▼
     [State Progression: DISCOVERED -> QUEUED -> ACQUIRING]
                              │
                              ▼
        [GEE Server-Side reduceRegion: REDUCING]
  (Extracts B2, B3, B4, B8, B11, B12 or VV, VH zonal distributions)
                              │
                              ▼
           [M5 Local Calculations: PROCESSING]
  (Computes NDVI, NDWI, NDBI, BSI, SAVI, EVI or VV, VH, VV-VH ratios)
                              │
                              ▼
       [M6/M7 Change Detection: CHANGE_ANALYSIS]
  (Evaluates differential raster statistics vs active/reference baseline)
                              │
                              ▼
       [Evidence Fusion & Alert: ALERT_EVALUATION]
  (40% Magnitude + 20% Quality + 20% Temporal + 20% Cross-Sensor)
  (<2% NONE | 2%-<5% LOW | 5%-<10% MEDIUM | >=10% HIGH)
                              │
                              ▼
            [Results Persistence: COMPLETED]
  (Links ProcessedImageResult, ChangeDetection, Alert & durationMs)
                              │
                              ▼
      [Ephemeral Cleanup in TempImageManager try ... finally]
```

## 6. Security & Invariant Audit

1. **Zero Key Storage:** Fully compliant with `iam.disableServiceAccountKeyCreation`. No service account `.json` keys are created or stored.
2. **Permanent Baseline Protection:** Temporary area incremental monitoring queries never create, mutate, or retire active permanent zone baselines.
3. **Sensor Track Isolation:** Optical-to-Optical and SAR-to-SAR isolation strictly maintained. Cross-sensor subtraction is impossible.
4. **No Fabricated Telemetry:** Satellite acquisition dates reflect authentic sensing timestamps; missing elevation/SAR data is flagged cleanly without fake pixel creation.
5. **Ephemeral Storage Cleanup:** `TempImageManager.withTemporaryWorkspace` guarantees 100% removal of temporary directories in both success and exception paths.
